# アクティブエピック（Active Epic: なし）

現在アクティブな Epic はありません。

このディレクトリは `spec-dock` が提供する **placeholder** であり、編集対象外です。

アクティブ対象を設定する例:

```bash
./spec-dock/scripts/spec-dock active set 123            # GitHub issue number
./spec-dock/scripts/spec-dock active set --github-issue 123
./spec-dock/scripts/spec-dock active set epic-00123     # node id（epic）
./spec-dock/scripts/spec-dock active set --id epic-00123
```
